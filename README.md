# Simple-Calculator-In-C

A simple command-line calculator built using C programming language. This project showcases the use of variables, user input (`scanf`), conditional logic (`if-else`), and `switch-case` statements.

## 🚀 Features
- Performs basic arithmetic operations: Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
- Includes error handling for division by zero.
- Formats results to 2 decimal places.

## 🛠️ How to Run
1. Copy the code into any C compiler or app (like Cxxdroid or Coding C).
2. Run the program.
3. Enter an operator first, then enter two numbers.
